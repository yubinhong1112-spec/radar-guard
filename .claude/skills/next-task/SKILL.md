# 다음 작업 시작

## 이 스킬이 있는 이유

Cowork(기획·설계)와 Claude Code(구현)는 **기억을 공유하지 않고, 서로를 직접 호출할 수도 없다.**
그래서 지시는 `HANDOFF.md` 에 파일로 남긴다. 사용자가 긴 지시를 손으로 옮기지 않아도 되게 하는 것이 이 스킬의 목적이다.

`HANDOFF.md` 는 **triage 를 거친 실행 지시서**다. 사용자가 그 자리에서 구두로 지시한 것과 같은 무게로 다룬다.

## 순서

### 0. 작업 지시 파일이 HANDOFF 보다 먼저다 (10/01)

**먼저 `04_문서/AI_BRIDGE/` 의 자기 도구 지시 파일을 읽는다** — 파일명에 `ClaudeCode` 또는 `Codex` 가 들어 있고, 자기 도구 이름이 들어간 쪽 하나만 연다.
- 상태가 `대기`/`진행중`이면 그 작업이 할 일이다. HANDOFF 는 참고만 한다.
- 상태가 `완료`면 그렇게 답하고 멈춘다. HANDOFF 로 넘어가 다른 일을 찾지 않는다.
- ⚠ [10/01] 이전 대화에서 받은 지시서 경로(`04_문서/설계/.../0N_*_지시.md` 등)나 압축된 대화 기억을 근거로 작업을 고르지 않는다. 그 파일들은 `_이전지시/` 로 옮겨진 폐기본이다. 실제로 Codex 가 압축 후 옛 지시서를 읽고 끝난 작업을 다시 돌린 일이 있었다.
- 그다음 `CLAUDE.md`/`AGENTS.md` §10 의 착수 보고 6항목으로 보고하고 사용자 확인을 받는다.

### 1. 읽는다 (지시 파일이 없을 때)

`HANDOFF.md` 전체를 읽는다. 세션 시작 시 로드됐더라도 **다시 읽는다** — Cowork 가 그 사이에 고쳤을 수 있다.

| 섹션 | 무엇을 얻는가 |
|---|---|
| `## Current objective` | 지금 무엇을 향해 가는가. **하나뿐이다** |
| `## Next actions` | 할 일. **최대 3개. 위에서부터 순서대로** |
| `## Blockers / unknowns` | 아직 답이 없는 것. 여기 걸린 항목은 **추측으로 진행하지 않는다** |
| `## Verified baseline` | 지금 어디까지 검증됐는가. 내 수정이 이 수치를 깨면 안 된다 |
| `## Acceptance` | 무엇을 만족해야 끝인가 |

**HANDOFF 는 자족적으로 쓰여 있다.** `BACKLOG.md` 나 `AI_BRIDGE/` 를 읽을 필요가 없고,
읽지 않는 것이 기본이다 — 거기엔 아직 지시가 아닌 것이 들어 있다.

### 2. 확인한다

- 지시가 **실제 코드와 맞는가.** 줄 번호·파일명이 어긋나면 그대로 진행하지 말고 알린다.
- `AGENTS.md`(또는 `CLAUDE.md`) §4 의 금지사항에 걸리지 않는가.
- 표시 계층을 건드리는 작업이면 **`radar-guard-hmi` 스킬을 먼저 읽는다.**
- **보류·중단 표시를 존중한다.** "손대지 말 것", "원인 규명까지만" 같은 제약이 있으면 그 선에서 멈춘다.

### 3. 시작 전에 말한다

- **무엇을** 할 것인가 (Next actions 의 몇 번인가)
- **어디를** 건드릴 것인가 (파일·함수)
- 이 작업에 걸리는 **제약**
- 끝나면 무엇으로 확인할 것인가

**승인 없이 코드를 고치지 않는다.** 원인을 먼저 글로 설명하고 승인받은 뒤에 고친다.

### 4. 어긋나면 멈춘다

지시가 실제 코드와 다르거나, 지시대로 하면 금지사항을 어기게 되면 **진행하지 말고 사용자에게 묻는다.**
임의로 판단해서 다르게 했다면 `04_문서/AI_BRIDGE/OUTBOX.md` 에 **무엇을 왜 다르게 했는지** 적는다.
말없이 다르게 하면 Cowork 가 틀린 문서를 쓴다.

### 5. 끝나면

`session-end` 스킬로 마무리한다 — 검증 → OUTBOX 기록 → HANDOFF 전체 재작성 → 형태 검사 → 커밋.

## 하지 말 것

- **작업 도중에 `HANDOFF.md` 를 고치는 것.** `session-end` 에서만 고친다.
- 막힘·판단 요청을 HANDOFF 의 Blockers 에 직접 쓰기 → `OUTBOX.md` 로 간다.
- Next actions 에 없는 작업을 임의로 끼워넣기.
- Next actions 가 비어 있는데 뭐라도 만들어내기 → "지시가 없다"고 알리고 무엇을 할지 묻는다.
- `BACKLOG.md` 나 `AI_BRIDGE/` 를 뒤져 할 일을 찾는 것. 거기 있는 것은 **아직 지시가 아니다.**
