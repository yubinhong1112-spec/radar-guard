## event_log.py 요구사항
- 표준 라이브러리만 사용(json, datetime, threading, pathlib, re).
- 저장: `03_데이터/운영기록/events_YYYYMMDD.jsonl` 에 한 줄씩 append. 경로는 저장소 루트 기준으로 계산하고 생성자 인자로 바꿀 수 있게(테스트는 임시 폴더 사용). 폴더 없으면 생성. 쓰기는 `threading.Lock` 으로 직렬화. 쓰기 실패는 예외를 밖으로 내지 말고 False 반환(관제 화면이 기록 실패로 멈추면 안 된다).
- 레코드: `{"ts": "2026-10-05T09:12:03+09:00", "kind": ..., "zone": ..., "event_type": ..., "detail": ..., "source": "operator"|"jetson"|"system"}`. ts 는 노트북 로컬 시각(Asia/Seoul) ISO8601.
- kind 고정 목록: `enter`(입실 확인), `exit`(퇴실 확인), `alert`(경보 발생), `ack`(경보 확인·경보음 정지), `resolve`(상황 종료), `restore_request`(전원 재투입 요청), `trip`(차단 확인), `link`(젯슨 연결/끊김). 목록 밖 kind 는 거부(False).
- 조회 함수(순수 함수, 파일 읽기만):
  - `count(kind, start, end, event_type=None, zone=None) -> int`
  - `last(kind, event_type=None) -> dict|None`
  - `list_events(kind, start, end) -> list[dict]`
  - 여러 날짜 파일에 걸친 구간도 처리. 깨진 줄은 건너뛰고 건너뛴 수를 반환값 옆 속성/로그로 알 수 있게.
- 한국어 기간 파서 `parse_period(text, now) -> (start, end, matched_text) | None` — **아래 형식만** 지원하고 나머지는 None(추측 금지):
  - `오늘`, `어제`
  - `N시부터 M시까지`, `N시~M시`, `N시에서 M시` (오늘 기준. M<N 이면 None)
  - `오전/오후 N시` 를 앞 형식 안에서 지원 (`오후 2시부터 5시까지` → 14~17시)
  - `최근 N시간`, `최근 N분`
  - 날짜 없는 시각은 `now` 의 날짜로 본다. 미래 구간이면 None.
- 질문 → 조회 파서 `parse_query(text, now) -> dict|None`: 지원 질문 4종만.
  1. 입실/퇴실 건수 (`입실`, `출입`→입실, `퇴실` + `몇 건|몇 번|건수|횟수`)
  2. 경보 건수·종류 (`경보` + `몇 번|몇 건|종류`)
  3. 마지막 경보 (`마지막 경보|최근 경보|가장 최근 경보`)
  4. 현재 차단 회로는 기록이 아니라 화면 상태라 **이 모듈 범위 밖** — `{"type": "current_trip"}` 만 반환하고 값은 채우지 않는다.
  - 기간이 없으면 기본 `오늘`. 반환에 `period_text` 를 넣어 답변에 "어떤 구간으로 셌는지"를 쓸 수 있게.
- 답변 문장 함수 `answer(query, log) -> str`: 템플릿 문장만(LLM 없음). 입·퇴실은 반드시 "운영자 확인 기준" 문구 포함(입·퇴실은 센서 추정이 아니라 운영자 버튼 값이다 — console_ui.py 1642 주석). 0건이면 0건이라고 쓰고, 기록 파일이 하나도 없으면 "해당 구간 기록 없음 — 기록 기능은 ○월 ○일부터 동작"처럼 기록 부재와 0건을 구분한다.
