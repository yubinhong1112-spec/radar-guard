## 배경 (사용자 결정 10/06)
경보 화면은 '즉시조치(사람 작성, `INSTANT_ACTION`) + AI 매뉴얼 보충 1~2줄(근거 chunk_id 표시, 사람 승인) + 실측 브리핑(코드)'로 간다.
T-CC04·05 에서 현행 프롬프트(즉시조치 + 발췌 → 4줄)는 즉시조치를 베끼거나(4/6종 동일 문장) 뜻을 뒤집었다(과전류 '교체 금지'→'교체'). 화면에 같은 4줄이 두 번 뜨는 문제도 있다(console_ui.py 1062 표시 순서). 그래서 AI 칸은 **즉시조치에 없는 매뉴얼 내용만** 생성한다. 사전 생성이라 시간은 길어도 된다.

## 2. 새 도구 `01_현행코드/eval/sop_supplement.py` (eval 안, 제품 코드 미사용 허용)
- 이번 프롬프트는 제품에 아직 없으므로 eval 에 새로 작성한다(제품 반영은 T-CC07). 프롬프트 원문 전체를 결과에 기록.
- 입력: 경보별 `pinned_chunks`(v2, 지정 순서, 본문 전체 — 자르지 않음) + 그 경보의 `INSTANT_ACTION` 문장 목록.
- 프롬프트 요지(한국어, 그대로 쓰지 않아도 되나 아래 제약은 모두 지킨다):
  - 역할: 산업 현장 안전관리 보조. 아래 [이미 화면에 있는 즉시조치]는 **반복하거나 바꿔 말하지 말 것**.
  - [공식 매뉴얼 발췌]에 있고 즉시조치에 없는 **현장 조치**만 최대 2개. 정의·설명·통계·예방 설계 내용은 제외.
  - 각 항목은 한 문장 40자 이내, 원문에 없는 수치·절차 금지, 각 항목에 근거 chunk_id 1개.
  - 해당 내용이 없으면 빈 목록.
- 호출: Ollama `format` 스키마 `{"items":[{"text":str,"chunk_id":str}]}`(maxItems 2), temperature 0, num_predict 400(JSON 잘림 방지 — T-CC05 판단 요청 3), num_ctx 는 발췌가 다 들어가게(최대 3072).
- 모델 2개: `qwen2.5:3b-instruct-q4_K_M`, `gemma2:2b`. 각 6종. 조건 사이 `ollama stop`.

## 3. 자동 검사 (각 항목별)
1. **근거 실재**: chunk_id 가 그 경보의 pinned_chunks 안에 있는가.
2. **근거 일치**: 항목 문장의 내용어(2글자 이상 한글 단어, 조사 제거 근사 가능)가 인용 청크 본문에 몇 % 나오는가. 50% 미만이면 '근거 약함' 표시(판정 아님, 표시만).
3. **즉시조치 중복**: INSTANT_ACTION 각 문장과의 문자 2-gram 자카드 유사도 최댓값. 0.5 이상이면 '중복 의심'.
4. **금지어**: 그 경보의 `must_not_include`(sop_eval_set.json) 적중.
5. **길이**: 40자 초과 표시.
6. **구 기준 수치**: `4∼5`, `4~5`, `1분간 100회` 적중.
- 검사 방법·임계값은 보고에 그대로 적는다(사람이 판단할 때 오해하지 않게).
