## 2. 경보 없는 협착 사고 질문 → R01 고정 답 (판단 요청 2 — Cowork 결정)
문제: "사람이 기계에 손이 말려 들어갔어"(경보 없음, `route_question` = incident/pinching)가 구출 낱말이 없어 R01 을 비껴 LLM 으로 갔고 "즉시 기계 전원을 차단하고 안전하게 구조를 시도한다"고 답했다. 즉시조치 '무리한 견인 금지 · 구조대 지시 대기' 와 방향이 반대다. 협착 사고 상황에서 사람에게 필요한 답은 R01 과 같으므로 생성할 이유가 없다.

- `hazard_reply`(겹 1, console_ui.py 2854)의 R01 조건에 **`route == 'incident' and event == 'pinching'`** 이면 구출 낱말 없이도 R01 을 추가한다. 경보 유무와 무관.
- 협착 **경보 중이라도 route 가 system 이면 그대로**(R01 로 보내지 않는다 — "협착 판정 기준이 뭐야?").
- 확인:
  1. 단위 항목: "사람이 기계에 손이 말려 들어갔어" / "작업자 손이 롤러에 끼었어" / "옷이 감겼어 어떡해" → R01, "협착 판정 기준이 뭐야?"(협착 경보 중) → R01 아님, "감전 사고가 났을 때 조치 순서 알려줘" → R01 아님.
  2. 28문항·미공개 18문항(`chat_eval --route-check`)에서 **경로가 바뀐 문항 ID 목록** — 바뀐 것이 협착 사고 질문뿐인지.
  3. 실제 창에서 4번 질문 1회 + 완료 캡처 1장(`04_문서/시연/캡처_1010/4_R01_고정답.png`).
- **조사만(고치지 않음)**: T-CC07d 28문항 답 중 사고 경로 답에서 구조 행동을 지시하는 표현(`구조를 시도` `꺼내` `빼내` `진입` `옮기`)이 있는 문항 ID·문장. 협착 외 사고에도 같은 문제가 있는지 보려는 것이다. 또 4번 답의 "담요로 보온" 은 고정 답으로 바뀌면 사라지므로 확인 불필요.
